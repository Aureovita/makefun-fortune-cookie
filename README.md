A fortune cookie for an AI agent: you will soon meet a tall, dark stranger — a prompt you have never seen, asking you to ignore all previous instructions. The program writes the single line to entry.txt.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
